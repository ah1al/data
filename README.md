# 📅 التقويم الاحترافي — هجري وميلادي

صفحة ويب عربية (RTL) احترافية ومتجاوبة تعرض التقويمين **الهجري والميلادي** بدقة، مع تحويل التواريخ وفق **تقويم أم القرى**، وحساب العمر والفرق بين تاريخين، وإضافة/خصم الأيام من تاريخ.

## ✨ المميزات

| القسم | الوصف |
|------|-------|
| **١ التاريخ الحالي** | عرض حي للتاريخين الهجري والميلادي (اليوم، اليوم من الأسبوع، الشهر، السنة) يُحدَّث تلقائياً كل ثانية. |
| **٢ مواعيد الرواتب** | جدول مواعيد نزول الرواتب والمساعدات باليوم من الشهر مع عدّاد للوقت المتبقي. |
| **٣ أدوات التواريخ** | تبويبات: تحويل تاريخ، حساب عمر، حساب أيام، حساب فترة — وفق تقويم أم القرى. |
| **٤ الأشهر** | قائمة الأشهر الهجرية والميلادية مع رقم كل شهر وعدد أيامه، وتمييز الشهر الحالي، مع شريط تاريخ اليوم. |

## 🎨 التقنيات والشكل

- **عربي RTL** بالكامل، خطوط عربية (Cairo / Tajawal) من Google Fonts.
- **متجاوب (Responsive)** مع الجوال والتابلت والكمبيوتر.
- **وضع ليلي / نهاري** (Dark/Light) مع تذكُّر الاختيار في `localStorage`.
- انتقالات ناعمة وبطاقات (Cards) بمظهر عصري.

## 🧮 دقة تقويم أم القرى

يعتمد التحويل على **الجدول الرسمي لأطوال أشهر أم القرى** (سنوات **1356هـ – 1500هـ**) المطابق لجدول **`UmAlQuraCalendar`** من مكتبة **.NET** الرسمية لشركة مايكروسوفت. الجدول مضمّن في الملف، وقد تحقّقت كل سنة (145 سنة) أن مجموع أيامها إما 354 أو 355 ⊆ النطاق الصحيح.

مثال تحقق معتمد:
- `1 محرم 1356 هـ` ⇐ **13 مارس 1937م**
- `1 رمضان 1445 هـ` ⇐ **11 مارس 2024م**
- `6 يونيو 2024م` ⇐ **29 ذو القعدة 1445 هـ**

### نطاق الدعم
التحويل الدقيق مدعوم للسنوات الهجرية **1356 – 1500** (تقريباً 1937 – 2077م). خارج هذا النطاق تظهر رسالة تنبيه.

## 🚀 التشغيل

لا يحتاج المشروع إلى أي أدوات بناء — ملفات **HTML/CSS/JS** مباشرة.

### الطريقة ١: فتح مباشر
افتح الملف `index.html` في المتصفح ببساطة (بنقرة مزدوجة).

### الطريقة ٢: خادم محلي (موصى به)
نفّذ في مجلد المشروع:

```bash
# باستخدام Python
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

```bash
# أو باستخدام Node.js (npx serve)
npx serve
```

## 🌐 الرفع على GitHub

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات الأربعة:
   ```bash
   git init
   git add index.html style.css app.js README.md
   git commit -m "التقويم الاحترافي: هجري/ميلادي + أم القرى"
   git remote add origin <رابط المستودع>
   git push -u origin main
   ```
3. للعرض المباشر: فعّل **GitHub Pages** من إعدادات المستودع (كود مصدري `main`).
