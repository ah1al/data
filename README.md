# 📅 التقويم الاحترافي — هجري وميلادي

صفحة ويب متجاوبة تعرض التاريخين **الهجري والميلادي** وتحوّلهما وفق **تقويم أم القرى**، مع حساب العمر والفرق بين تاريخين والمواعيد العامة للرواتب.

## المميزات
- التاريخ الحالي هجري/ميلادي حيّ.
- مواعيد نزول الرواتب مع عدّاد متبقٍ.
- تحويل تاريخ · حساب عمر · إضافة أيام · حساب فترة.
- أشهر السنة مع تمييز الشهر الحالي.
- دعم **العربية (RTL) والإنجليزية (LTR)** + وضع ليلي/نهاري.

## دقة أم القرى
التحويل من الجدول الرسمي لأطوال الأشهر (1356هـ–1500هـ) المطابق لـ `UmAlQuraCalendar` (.NET).

## التشغيل
لا يحتاج بناءً — افتح `index.html` مباشرة، أو:
```bash
python -m http.server 8080
```

## الهيكل
```
index.html   # الصفحة
style.css    # التنسيقات
app.js       # المنطق والحسابات
```
