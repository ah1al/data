# 📅 التقويم الاحترافي — هجري وميلادي

صفحة ويب متجاوبة تعرض التاريخين الهجري والميلادي وتحولهما وفق تقويم أم القرى مع حساب العمر والفرق بين تاريخين والمواعيد العامة للرواتب

## المميزات
- التاريخ الحالي هجري وميلادي حي
- مواعيد نزول الرواتب مععداد متبق
- تحويل تاريخ وحساب عمر وإضافة أيام وحساب فترة
- أشهر السنة مع تمييز الشهر الحالي
- دعم العربية RTL والإنجليزية LTR ووضع ليلي ونهاري

## دقة أم القرى
التحويل من الجدول الرسمي لأطوال الأشهر 1356هـ حتى 1500هـ المطابق لـ UmAlQuraCalendar
